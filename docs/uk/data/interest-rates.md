# Процентні ставки {#interest-rates}

Файл: `data/interest-rates.json`. Джерело: FOD Financiën (федеральне міністерство фінансів),
опубліковано в Belgisch Staatsblad / Moniteur belge.

## Чим він корисний {#why-it-s-useful}

Проценти за прострочення платежу є частиною майже кожної вимоги, а ставка залежить від дня:

- **Законні проценти** (wettelijke interest / intérêt légal) застосовуються до боргів загалом,
  і саме їх суди присуджують як мораторні проценти, якщо договір чи спеціальний закон не
  передбачає іншого.
- **Комерційні проценти** (Wet 2 augustus 2002) застосовуються до прострочених платежів між
  підприємствами і перед органами влади, якщо договір не встановлює вищої ставки.

Вимога, що охоплює кілька років, перетинає кілька періодів, кожен зі своєю ставкою. Помилка в
одному періоді змінює суму вимоги, а перехід 2013–2015 років (див. нижче) легко пропустити.
`getInterestRate` дає правильну ставку для дня і повертає `null` замість того, щоб вгадувати,
коли ставку ще не опубліковано.

- **Законна** (`legal`, wettelijke interest, Wet 5 mei 1865): встановлюється на календарний рік;
  є в даних з 1970 року.
- **Комерційна** (`commercial`, прострочення платежів у комерційних операціях, Wet 2 augustus
  2002): встановлюється на півріччя; є в даних з 2002 року.

## Правило договорів 2013–2015 років {#the-2013-2015-contract-rule}

З 2013 року до 15 березня 2015 року комерційна ставка залежить від того, коли укладено договір.
Ці періоди мають додаткове поле `rateForContractsBefore20130316`. За замовчуванням
`getInterestRate` повертає ставку для старіших договорів; передайте
`{ contractAfter20130316: true }` для договорів, укладених 16 березня 2013 року або пізніше.

```ts
getInterestRate('2014-06-15', 'commercial') // { rate: 7.5, … }
getInterestRate('2014-06-15', 'commercial', { contractAfter20130316: true }) // { rate: 8.5, … }
```

## Відсутні періоди {#missing-periods}

`getInterestRate` повертає `null` для дня, для якого ставка невідома: до першого періоду або
для періоду, який ще не опубліковано (чи не додано). Використовуйте
`getLatestKnownRateDate(type)`, щоб показати, докуди сягають дані, і виводьте попередження
замість того, щоб мовчки використати 0 %.

## Структура {#shape}

```ts
type InterestType = 'legal' | 'commercial'

interface InterestRateSeries {
    description: string
    source: string
    periods: InterestRatePeriod[]
}

interface InterestRatePeriod {
    from: string // перший день, включно, YYYY-MM-DD
    to: string // останній день, включно, YYYY-MM-DD
    rate: number // відсотки
    rateForContractsBefore20130316?: number
    note?: string
}
```
